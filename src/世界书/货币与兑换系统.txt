<货币与兑换系统>
货币与兑换系统:
  一_货币体系总览:
    奖励点(分数): 购买属性/装备/消耗品，支付主神医疗服务。可同队交易
    支线剧情(D/C/B/A/S): 购买血统/改造/瞳术等模板能力。3低换1高(3D=1C)，1高拆3低(1C=3D)。可同队交易
    经验值_XP: 提升技能/专长/自学能力。不可交易
    兑换限制: 三种货币不可直接兑换(精神时光屋为唯一间接途径，用支线+奖励点换XP)
    兑换地点: 支线+奖励点仅限主神空间使用；XP可在主神空间或冒险世界使用(冒险世界中消耗×2)
  二_奖励点与支线获取:
    难度评估参考(五档):
      毫无威胁: 1-10分(大量小怪)
      非常简单: 50-500分(精英小怪)
      势均力敌: D-C级支线+对应分(小BOSS)
      颇具挑战: C-B级支线+对应分(大BOSS)
      致命威胁: B级以上支线+对应分(隐藏BOSS)
    常规获取:
      主线任务: D级1000分至A级10000点(依副本难度)
      支线任务: D级500分至A级10000+分
      击杀怪物: 普通10-50/精英100-500/BOSS1000-5000
      特殊: 存活奖励1000分；新人首位引导100分；改变剧情额外奖励
    团战结算:
      胜负积分: 击杀敌方+1分，己方被杀-1分(死因不限)。结算时每正分全员+2000点，每负分全员-2000点
      击杀基础: 杀未开锁者D+1000点；杀已开锁者C+2000点；杀敌方队长B+6000点；团灭敌方全员得C级支线
      战利品: 击杀者额外获得目标历史消耗最高支线次一级的支线，及剩余奖励点的1/3
      自相残杀: 击杀队友立即扣除B+4000点，不足则抹杀
  三_经验值获取:
    总经验 = 基础值 + 奖励经验 + 特殊表现
    基础值: 2+2n点(n=冒险世界次数)。第1场4XP，第2场6XP，类推
    奖励经验: 获得支线数×3 + 总分数/500×2，向上取整
    表现奖励: 从E到SSS，每一级+2
    传奇智力红利: 每1点传奇智力额外+4XP
    发放时机: 恐怖片结束后统一发放
  四_强化分类限制:
    模板能力: 血统、改造、瞳术、修炼体系、典籍。
    非模板能力: 称号流派(同一总纲下分支互斥)、能量池、技艺/法术/招式、物品。无特殊说明不具排他性
  五_基础价格速查表:
    血统/改造: D级(D+600/500) / C级(C+1200/1000) / B级(B+3600/2000) / A级(A+7200/4000) / S级(S+14400/8000)
    技艺法术: D级(D+500) / C级(C+1000) / B级(B+2000) / A级(A+4000) / S级(S+8000)
    专长: 1级3XP / 2级6XP / 3级9XP / 4级12XP / 5级15XP
    技能: 提升需(当前等级×2)XP。从0到1需1XP。上限15级
  六_自学规则:
    范围: 已解锁模板的技能树内容、流派技能、通用法术技艺。不可自学模板本身或实体物品
    XP消耗: 无支线3XP / D+500=9XP / D+1000=12XP / C+1000=27XP / C+2000=36XP / B+2000=81XP / B+4000=108XP / A+4000=243XP / A+8000=324XP / S+8000=729XP / S+16000=972XP
    公式: 支线转分数(每D=500)，总分/500×3=所需XP
  七_主神服务:
    强化属性: 1点基础属性为当前属性*200分/*4XP；从0到1需要100分/1XP
    医疗: 冲击/严重/恶性伤害免费；解除不良状态免费；治疗基因崩坏500/分；全身修复10-1000分（根据伤势）；永久精神失常1000分。属性丢失无法修复
    培元固本: 永久提升HP上限，第1次+1/第2次+3/第3次+5，上限使用3次，每次500分，每两次冒险间限一次
    复活: 花费=角色曾消耗的全部支线分数之和+1000分。自爆/爆体/不可复活能力死者无法复活
    精神时光屋: D+1000兑换12XP(唯一货币间接转换渠道)。ST需安排虚拟战斗或心魔试炼增强扮演体验
</货币与兑换系统>
