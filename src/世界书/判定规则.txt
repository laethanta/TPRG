<判定规则>
判定规则:
  零、核心术语:
    基调: 本规则为“D10骰池（用于常规检定/战斗/先攻/豁免/特定判定）”系统，需严格区分适用场景，NSFW场景禁止任何检定。
    DP (Dice Pool): 骰池，即一次检定中需要投掷的骰子总数量。
    DC (Difficulty Class): 难度等级，即检定成功所需的“最终成功数”门槛，成功数超出DC越多，行动越成功，反之则行动失败。
    ST (Storyteller): 游戏主持人与裁判
  一、核心检定规则_D10骰池:
    DP构成: 检定DP = 相关属性 + 相关技能 + 专业加值 ± 其他调整值 + 完美加值
    成功条件: 骰面出目8、9、10计为1个成功。最终成功数 = 投掷成功数(自然成功) + 附加成功
    注意事项:
     - 属性与技能的对应关系由ST根据行动意图裁定，可参考<属性概述>。
     - 完美加值可以与任何加值类型叠加，包括与其他完美加值叠加
    附加成功: 传奇属性、高级技能或其他能力提供。若投掷成功数≤0，则行动失败，附加成功不生效。
    加骰机制:
      - 10加骰: 默认情况下，掷出10额外加投1枚D10，再次出10继续加投，无理论上限
      - 其他加骰: 特定能力或道具提供“8/9加骰”效果，掷出8/9或10均可加投，加骰的最低值为8
      - 加骰的骰子同样遵循成功条件判定。
    机运骰: 当检定DP降至0或以下时可投1枚D10。出10才会记1个成功并可正常进行加骰；如果出1则为*大失败*（前面出10加骰则出1不算），由ST裁定具体不利后果。机运骰不吃任何增加DP的能力
  二、难度等级基准_DC:
    DC1: 日常事务 (普通人即可完成)
    DC2: 稍有挑战 (需一定技巧)
    DC3: 困难 (专业人士水准)
    DC4: 极难 (精英专家领域)
    DC5及以上: 传说 (凡人几乎不可能)
  三、检定类型细则:
    对抗检定: 双方各自进行检定，比较最终成功数，高者胜出。平局通常视为带有目的性的主动方失败（例: A潜行背刺B，平局则A被发现）或维持现状（AB扳手腕则平局），具体由ST裁定
    周期性检定: 用于修理、破解、追踪等需要长时间累积进度的行为。ST设定总DC与单次检定的时间周期、以及可尝试的次数上限。若时间耗尽未达DC则失败且不返还消耗
    百分比判定: 提取2枚D10组合为D100（第一枚为十位，第二枚为个位，两枚均为10则为100）。常用于检定战利品掉落、随机事件的稀有度、剧情分支或环境变化等概率事件。
  四、战斗特定检定:
    攻击DP构成:
      - 近战肉搏: 力量 + 肉搏 + 天生武器伤害 - 目标防御
      - 近战白刃: 力量 + 白刃 + 武器伤害 - 目标防御
      - 远程枪械: 敏捷 + 枪械 + 武器伤害 - 目标防御 - 距离减值
      - 远程弓箭: 敏捷 + 弓箭 + 武器伤害 - 目标防御 - 距离减值
      - 施法攻击: 智力 + 神秘学 + 法术威力 - 目标防御
    命中与伤害:
      - 命中判定: 若目标【防御附加成功】大于攻击方【自然成功数】，则攻击直接失败(未命中)，攻击方附加成功失效。
      - 最终成功数 = 自然成功数 + 攻击附加成功 - 目标防御附加成功 (≤0为未命中)
      - 1点最终成功数造成1点伤害。分为冲击(B)、严重(L)、恶性(A)
      - 伤害上限 = 武器伤害 + 关键属性 + 关键技能 (枪械为武器伤害×2 + 枪械)
    减伤结算顺序: 伤害免疫 > 伤害忽略 > 硬度 > 伤害吸收 > 伤害转化 > 能量抗力/DR > 伤害抵消
  五、先攻与豁免检定系统:
    先攻判定: 1D10+人物的先攻值（通常为 敏捷 + 沉着），若没有临时改变先攻的能力，则总是使用该结果。
      - 先攻判定*不视为检定*，不吃任何影响检定结果的能力影响，除非该能力拥有特殊说明。
      - 先攻权相同时，沉着较高者先动。若沉着也相同，则敏捷较高者先动。若仍相同，则可以扔1D10决定。
      - 无论如何，先攻不会降低为负数，最低为1
    豁免检定: 进行豁免检定时，即使没有对应专业，也不会受到无专业惩罚。
      - 意志豁免: 决心 + 沉着 + 相关加值。用于抵御心灵影响、精神伤害。
      - 反射豁免: 敏捷 + 运动 + 相关加值。用于回避范围攻击、陷阱。
      - 强韧豁免: 耐力 + 求生 + 相关加值。用于抵抗毒素、疾病、生理影响。
  六、骰子使用协议:
    所有判定*必须*从<骰子池>生成的骰子组中，按编号顺序消耗。不可跳跃、挑选或重用。
    当一次检定所需DP数量超过当前组剩余骰子时，继续从下一组顺序取用。不可混用骰池。
  七、基础运算协议:
    小数舍入: 任何涉及数值与资源的计算，出现小数时无条件向下取整。
    负数计算: 因被动效果（含不可控代价）扣减至0以下的数值在计算影响时视为0。若能力允许主动支付代价降至负数，目标针对该数值对你发起主动行为时获得等同该负数的完美加值。
    乘法合并: 存在多个乘数时，先将额外乘数减一后加到第一个乘数上进行合并，再进行加数运算。(例:2倍速+4倍速 = 5倍速)。
    多骰取高低: 类似乘法合并，基础为1次，额外次数相加减。(例:3次取高与2次取高 = 投4次取高；2次取高与2次取低 = 投1次)。
</判定规则>
