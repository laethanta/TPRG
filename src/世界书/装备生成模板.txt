装备生成模板: 
 一、武器数据结构:
    通用模板，所有武器共享以下数据结构，ST生成新武器时需逐项填写：
    ```
    名称：[武器名]
    本质：[自然/科技/魔幻]
    分类：[长剑/手枪/弓/投掷等]
    前提：[属性要求/技能要求/专业要求（如 力量3，白刃2，专业：长剑）]
    体积：[数值]
    武器伤害：[数值 + 类型，如 4L（4点严重伤害）]
    武器特殊属性：[破甲X / 破魔X / 高速X / 贯穿 / 连射 / 威猛 / 眩晕 / 沉重 / 格挡 等]
    特性：[特殊效果描述（若有）]
    价格：[奖励点，若有支线要求需注明]
    描述：[风味文字]
    ```
    伤害类型: 冲击(B/钝击震荡)、严重(L/切割枪击)、恶性(A/强酸神圣分解)
    常见特殊属性: 破甲(忽略天生/盔甲防御)、破魔(忽略法术抗力)、高速(抵消高速优势)、贯穿(攻击多目标)、连射(多发攻击)、威猛(提升器械加值上限)、眩晕(造成眩晕点数)、沉重(体积与重量提升)、格挡(提供格挡加值)
  二、防具数据结构:
    通用结构: 
    ```
    名称：[防具名]
    本质：[自然/科技/魔幻]
    分类：[轻甲/中甲/重甲/盾牌]
    前提：[属性要求（如 力量3）]
    体积：[数值]
    盔甲防御：[数值]
    盔甲减值：[数值]（对着装者【敏捷】相关技能检定的直接 DP 扣减）
    敏捷上限：[数值]（着装者在计算基础防御时，敏捷值不能超过此上限）
    特殊属性：[防弹 / 防能量 / 封闭 / 环境适应 等]
    特性：[特殊效果描述（若有）]
    价格：[奖励点，若有支线要求需注明]
    描述：[风味文字]
    ```
    分类特征:
      轻甲: 低防御，无/低减值，高敏捷上限
      中甲: 中防御，中减值，中敏捷上限
      重甲: 高防御，高减值，低敏捷上限，附带特殊抗性
      盾牌: 提供格挡防御加值，需手持
    多重着甲: 重甲内可穿轻甲。盔甲防御取最高，特殊属性仅最内层生效，破甲逐层突破，盔甲减值叠加
  三、消耗品模板:
    所有消耗品使用一次即失效，不可投影或复制。
    ```
    名称：[物品名]
    本质：[自然/科技/魔幻]
    分类：[医疗/食物/弹药/工具]
    效果：[具体效果描述，包含检定加值、恢复量、持续时间等]
    价格：[奖励点，高级消耗品需支线]
    描述：[风味文字]
    ```
