  世界记录.当前影片信息:
    type: |-
      {
        名称: string;
        类型: string;
        难度评级: string;
        本质倾向: string;
        当前区域: string;
        当前地标: string;
        当前时间: string;
      }
    check:
      - "当前时间: 格式如 YYYY-MM-DD HH:mm，随剧情时间流逝推进"
      - "当前区域 / 当前地标: 场景转移时实时更新"
      - "返回主神空间: 当剧情返回主神空间后，必须将名称改为'主神空间'，当前时间改为'倒计时10天'（随日常流逝扣减），类型/难度评级/本质倾向均改为'无'。"

          失败惩罚?: string;

      }
    check:
      - 触发支线或主神发布主线时新增记录
      - 达成条件或超时后，修改当前状态
      - "返回主神空间结算: 返回主神空间后，立即根据各任务完成情况结算经验值和资源，结算完毕后清空所有任务日志记录。"

  世界记录.主神空间档案.主神商店当前列表:

  轮回者.生理与状态:
    type: |-
      {
        生命状态: { 完好: number; 冲击B: number; 严重L: number; 恶性A: number; };

      - "增益状态: 获得加速、隐形、防护等非数值型BUFF时添加状态名；持续时间结束或主动解除时移除"
