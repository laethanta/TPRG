  主角.属性面板:
    type: |-
      {
        力量: { 基础值: number; };

    check:
      - "基础值：仅在主神空间花费分数强化，或经历剧情获得永久属性成长时由 ST 手动更新数值"

  主角.技能列表:
    type: |-
      {
        [技能名称: string]: { 等级: number; 已解锁专业: string[]; };
      }
    check:
      - "技能名称可以是设定的基础19项（运动、肉搏、驾驶、枪械、手上功夫、隐藏、求生、白刃、学识、电脑、手艺、调查、医学、神秘学、科学、动物沟通、感受、表达、胁迫、交际、掩饰。），也可以是特定子技能（格式必须为 '主分类-子类'，例如：'手艺-制造科技盔甲'、'表达-演奏'）"
      - "仅在花费 XP 升级，或剧情中学习时更新技能等级"
      - "基础技能达到3级或4级时可免费获得一个专业（记录在已解锁专业数组中）；如果是 '手艺-制造' 这种子技能，其子分类名本身就是专业，直接通过子技能名生效，无需填入已解锁专业"


  主角.特质与模板.专长列表:

      {

          前提: string;
          描述: string;

          关键词: string;

      }
    check:
      - "名称右边写点数，缺陷为负（例：傲人身材（0））"
      - "在主神空间兑换专长或在剧情中领悟/获得缺陷时新增记录"
      - "关键词只能写用【】包裹的简述，例如：【防弹】、【无限弹药】"

  主角.生理与状态:
    type: |-
      {
        生命状态: { 完好: number; 冲击B: number; 严重L: number; 恶性A: number; };
        当前意志力: number;
        能量池: { 名称: string; 当前值: number; 基础上限加成: number; };
        不良状态点数: { [状态名: string]: number };
        固有状态: string[];
        增益状态: string[];
        基因锁: { 最高已开启阶数: number; 熟练度: number; 当前处于开启阶数: number; 反噬记录: object; };
      }
    check:
      - "生命状态: 仅记录受到伤害或治疗的绝对值增减，禁止自行计算满溢转化"
      - "不良状态点数: 遭受流血、剧痛等时增加数值，仅记录数值，不记录轻/重度"
      - "固有状态: 遭受倒地、昏迷、失能时添加，解除时移除"
      - "增益状态: 获得加速、隐形、防护等非数值型BUFF时添加状态名；持续时间结束或主动解除时移除"
      - "基因锁: 战斗中无论是否曾开启过该阶基因锁，每轮熟练度均自动 +2。开启时更新当前阶数和记录开启轮数；关闭或战斗结束时，根据反噬规则由脚本自动扣除属性或增加状态，此处重置当前阶数为0并记录反噬轮数即可"
