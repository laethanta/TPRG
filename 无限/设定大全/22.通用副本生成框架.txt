<通用副本生成框架>
副本生成框架:
  说明: 规范ST创建自定义副本或即兴生成世界时的要素，保证游戏可运行性与数值自洽
  一_副本结构要素:
    基础信息:
      - 副本名称: 电影/游戏/小说/原创名称
      - 原作类型: 科幻/奇幻/恐怖/现实/废土等
      - 难度评级: D/C/B/A/S (对应支线等级，决定奖励与敌人强度)
      - 建议轮回次数: 0-2次 / 3-5次 / 6-10次 / 10-15次 / 15+次
      - 时间跨度: 通常几天至数月，最长不超过1年
      - 本质倾向: 科技/魔幻/特异/自然/高维。若能力本质与世界倾向严重冲突(如无魔世界使用魔导书)，该能力需承受严重减值甚至失效
    世界背景:
      时代设定/地理位置/核心冲突/独特规则(无则写无)/环境基调(视/听/嗅觉氛围，1-2句)
    主线任务:
      任务目标: 必须完成的具体条件
      时间限制: 倒计时或截止时间，超时判定失败
      失败惩罚: 扣除奖励点或抹杀(奖励点归零即抹杀)
      成功奖励: 基础奖励点+支线剧情
    威胁分级:
      环境威胁: 极端天气/毒素/辐射/特殊重力等
      生物威胁: 怪物类型/数量/特殊能力
      人为威胁: 敌对势力/阴谋/NPC背叛/社会压迫
      特殊威胁: 独有致命机制(诅咒/时空紊乱/规则改写)
    关键资源与获取:
      可获取物品: 特有武器/道具/资源
      可习得技能/法术: 需满足前提与剧情耗时
      可带回空间: 消耗奖励点/支线解锁永久保留
      获取规则: 特殊物品须通过检定或剧情行为获取，不得直接拾取
    NPC清单:
      友方/中立/敌方/隐藏NPC，标注立场、关键属性、触发条件
    环境与战术影响:
      视距/地形/温度/特殊环境对检定、移动、生存的具体影响
    支线与隐藏机会:
      隐藏任务/剧情分歧点/特殊结局及触发条件。接近时可给模糊提示
  二_难度数值校准:
    梯队划分:
      新手(0-2次): 无超自然，普通武器，技能2-3级
      进阶(3-5次): D级血统，传奇属性，魔法武器，技能3-5级
      精英(6-10次): C/B级血统，高阶法术，技能5-8级，1阶基因锁
      噩梦(11-15次): B/A级血统，技能8-12级，2阶基因锁
      神话(15+次): A/S级血统，技能12-15级，3阶+基因锁
    敌人数值速查(单体基准，非强制公式，ST可自行调整):
      - HP: 5-10→10-20→20-40→40-80→100+
      - 攻击DP: 3-6→5-9→8-14→12-18→16-24+
      - 附加成功: 0→0-1→1-3→4-8→10+
      - 防御: 2-4→3-5→5-8→7-11→10-16+
    主线奖励基准:
      D级: 500-1000点 / C级: 1000-2000点 / B级: 2000-4000点 / A级: 4000-8000点 / S级: 8000+点
    弹性调整: 若玩家过强或过弱，ST可动态调整敌人波次、伤害或数量
  三_开场描写模板:
    模板结构:
      - [副本名称] - 故事开端:
        - [场景描写]: (渲染副本的视觉、听觉、嗅觉等感官信息，奠定基调。)
        - [玩家状态]: (描述玩家进入副本时的初始状态，包括装备、伤势、已知信息等。)
        - [触发事件/NPC]: (引入第一个与玩家互动的NPC，或发生一个引导玩家行动的事件。)
        - [核心目标提示]: (隐晦或直接地告知玩家本副本的主要目标或当前紧迫的危机。)
    描写风格: (可根据副本原作风格进行调整，如：悬疑、惊悚、史诗、幽默等。)
    主神提示(Markdown格式):
```
══════════════════════════════════
              【主线任务】
  任务目标：[具体目标]
  时间限制：[倒计时或期限]
  失败惩罚：[惩罚内容]

  成功奖励：[奖励点+支线]
══════════════════════════════════
```
    初始选择（1-2句）：描述周围可见的选项/路径/人物，等待玩家行动。
开场示例——生化危机1：
空气中弥漫着腐肉与消毒水混合的气味。你睁开眼，发现自己躺在一张冰冷的金属手术台上，刺眼的白炽灯从头顶直射下来。主神淡白色的半透明防护罩正将你笼罩其中，走廊尽头隐约传来拖拽声和低沉的喉音。你的脑海中响起了冰冷的提示音：
```
══════════════════════════════════
              【主线任务】
  任务目标：存活72小时并逃离洋馆
  时间限制：72小时
  失败惩罚：抹杀

  成功奖励：1000奖励点 + D级支线
══════════════════════════════════
```
随着主神防护罩的消失，手术室的门半开着。你身上只穿着一件单薄的病号服，手边有一把生锈的手术刀（武器伤害2L，体积1）和半瓶止痛药。走廊左侧传来沉重的脚步声，右侧则是一扇标着"EXIT"的安全门。你该如何行动？
