## 装备与物品系统
### 一、物品本质与分类
所有物品拥有一个**本质**标签，决定其底层运作规则：
| 本质 | 说明 |
|:---|:---|
| 自然 | 普通物理法则下的物品，不涉及超自然力量 |
| 科技 | 依靠科技原理运作，可能受EMP等科技手段影响 |
| 魔幻 | 依靠魔法/超自然力量运作，可能被反魔法能力压制 |
物品分为以下类别：**武器、防具、消耗品、特殊物品**（剧情道具/空间装置等）。
### 二、武器通用属性模板
所有武器共享以下数据结构，ST生成新武器时需逐项填写：
```
名称：[武器名]
本质：[自然/科技/魔幻]
分类：[长剑/手枪/弓/投掷等]
前提：[属性要求/技能要求/专业要求（如 力量3，白刃2，专业：长剑）]
体积：[数值]
武器伤害：[数值 + 类型，如 4L（4点严重伤害）]
武器特殊属性：[破甲X / 破魔X / 高速X / 贯穿 / 连射 / 威猛 / 眩晕 / 沉重 / 长柄 / 格挡 等]
特性：[特殊效果描述（若有）]
价格：[奖励点，若有支线要求需注明]
描述：[风味文字]
```
**武器伤害类型**：
| 缩写 | 类型 | 说明 |
|:---|:---|:---|
| B | 冲击伤害 | 钝击、震荡等非穿透性伤害 |
| L | 严重伤害 | 利刃切割、枪击等穿透性伤害 |
| A | 恶性伤害 | 强酸、神圣、分解等毁灭性伤害 |
**常见武器特殊属性速查**：
| 属性 | 效果 |
|:---|:---|
| 破甲X | 攻击时忽略目标X点盔甲防御或天生防御 |
| 破魔X | 攻击时忽略目标X点法术抗力或魔法防御 |
| 高速X | 攻击时抵消目标X点高速优势 |
| 贯穿 | 成功命中后，可对目标身后直线上的另一目标继续造成伤害（伤害递减） |
| 连射 | 每消耗额外弹药，可多攻击一个目标或对同一目标追加判定 |
| 威猛 | 武器伤害的器械加值上限提升 |
| 眩晕 | 命中后目标需强韧豁免，失败获得眩晕点数 |
| 沉重 | 武器体积大，力量不足时承受攻击减值 |
| 长柄 | 近战触及范围增加 |
| 格挡X | 用于格挡时提供X点格挡防御 |
| 防弹 | 对枪械弹药提供额外防御 |
| 防能量武器 | 对能量武器攻击提供额外防御 |
### 三、防具通用属性模板
```
名称：[防具名]
本质：[自然/科技/魔幻]
分类：[轻甲/中甲/重甲/盾牌]
前提：[属性要求（如 力量3）]
体积：[数值]
盔甲防御：[数值]
盔甲减值：[数值]（对着装者【敏捷】相关技能检定的直接 DP 扣减）
敏捷上限：[数值]（着装者在计算基础防御时，敏捷值不能超过此上限）
特殊属性：[防弹 / 防能量 / 封闭 / 环境适应 等]
特性：[特殊效果描述（若有）]
价格：[奖励点，若有支线要求需注明]
描述：[风味文字]
```
**防具分类规则**：
| 类型 | 特征 |
|:---|:---|
| 轻甲 | 低防御，无/低减值，高敏捷上限 |
| 中甲 | 中等防御，中等减值，中等敏捷上限 |
| 重甲 | 高防御，高减值，低敏捷上限，通常附带特殊抗性 |
| 盾牌 | 提供格挡防御加值，需手持，部分附带【格挡X】特性 |
**多重着甲规则**：可在一件重甲内穿一件轻甲。盔甲防御取最高者而非叠加，特殊属性仅最内层生效。破甲值需逐层突破，盔甲减值叠加。
### 四、消耗品模板
所有消耗品使用一次即失效，不可投影或复制。
```
名称：[物品名]
本质：[自然/科技/魔幻]
分类：[医疗/食物/弹药/工具]
效果：[具体效果描述，包含检定加值、恢复量、持续时间等]
价格：[奖励点，高级消耗品需支线]
描述：[风味文字]
```
### 五、物品等级与价格映射
物品的稀有度与强度直接与其*支线等级*挂钩。ST在生成非制式装备时，遵循以下强度基准：
| 等级 | 价格参考 | 属性加成 | 特殊效果 |
|:---:|:---|:---:|:---:|
| 普通 | 10~500 点 | 无 | 无超自然特性 |
| D级 | D + 500~1000点 | 基础+1 | 1项基础特性 |
| C级 | C + 1500~2000点 | 基础+2 | 1~2项强力特性 |
| B级 | B + 3000~4000点 | 基础+3 | 3条质变特性 / 自带B级法术 |
| A级 | A + 8000~10000点 | 基础+4 | 4条特性/扭转战局的因果律特性 |
| S级 | S + 16000点以上 | 基础+5 | 独特被动能力 |
- “基础+X”指武器伤害、盔甲防御等核心数值的提升
- 特性由ST根据品质等级从武器特殊属性库中选取或自行设计
### 六、背包、装备位与体积参考
**1. 装备位**
角色拥有以下有效装备位，同部位穿戴多件超自然物品时，**仅支线等级最高者生效**（凡人物品不受此限但受多重着甲限制）：
[头盔位]、[护符/项链位]、[披风位]、[躯干盔甲位]、[腰带位]、[手套位]、[戒指位(最多2枚)]、[鞋靴位]、[手持位(双手)]。
**2. 负重与敏捷惩罚系统**
*日常探索免计算负重。仅当携带重物超出下表阈值时，施加对应减值。*
| 力量值 | 轻度负荷 (正常) | 中度负荷 (-2DP，移速-1/3) | 重度负荷 (-5DP，移速减半，无闪避) |
|:---:|:---:|:---:|:---:|
| 1 - 2 | ≤ 20 kg | 21 - 40 kg | 41 - 60 kg |
| 3 - 4 | ≤ 40 kg | 41 - 80 kg | 81 - 120 kg |
| 5 (凡人极限)| ≤ 60 kg | 61 - 120 kg | 121 - 180 kg |
| 6+ (超凡领域)| 力量值 × 20 kg | 力量值 × 40 kg | 力量值 × 60 kg |
- **传奇力量**：额外增加 500 × 2^(n-1) kg 负重，n=1点传奇力量。
- **超限**：当前负重 > 重度负荷上限，角色无法移动，必须丢弃物品。
**3. 空间存储装置与体积锚点**
|空间装置内部时间静止（不可放入活物，食物不腐）。
| 类型 | 容量限制 (总体积) | 价格参考 |
|:---|:---:|:---|
| 战术腰包 | 体积 10 | 200 奖励点 |
| 小型空间袋 | 体积 50 | D支线 + 1000 奖励点 |
| 中型空间指环| 体积 100 | C支线 + 2000 奖励点 |
*【体积锚点参考】：指环/钥匙(0.1)；匕首/手枪/药剂(1)；长剑/步枪(3)；重型狙击/单兵火箭筒(4)；成年人类(7)；越野车(20)。*
**1. NPC 交易议价**
玩家通过 操控+交际（交涉） 与剧情人物交易时，每1个最终成功数可获得 5% 的溢价/折扣（极限为 30%）。
**2. 主神回收法则（残缺折价）**
- **不可回收**：消耗品（含使用次数未满的道具）、剧情世界带回的无支线物品、自制品。
- **折旧率**：必须是满耐久完好状态。破损物品需先花钱修复才能回收。
- **退还公式**：
  - 奖励点退还 **50%**。
  - 支线等级采用【降级折算】：退还 **2个** 降一级的支线（例如：回收C级物品，退还2个D级支线。回收B级退还2个C级）。
  - **D级物品回收不退还任何支线**，仅退还奖励点。
**3. 耐久与破坏规则**
*AI裁判无需在日常攻击中追踪物品结构值。*
仅在以下情况触发装备损坏判定：
1. 玩家使用武器格挡导致大失败。
2. 遭遇针对性极强的攻击（如腐蚀酸液、分解射线、粉碎专长）。
3. 使用D级常规兵器强行招架B级以上高维打击。
判定毁损时，装备失去一切加成，需返回主神空间花费 10%~30% 原价修复，或在任务中使用【手艺】技能进行长周期延长检定维修。
