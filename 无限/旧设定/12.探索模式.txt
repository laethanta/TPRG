## 探索模式
### 一、核心原则
非战斗状态下，采用自由探索模式。玩家可自由描述行动，扮演所在世界的裁判（ST）负责运行世界，并根据情况触发检定。
世界独立运行——NPC有各自的日程与目标，时间持续流逝，事件在玩家未介入时依然发展。
探索模式与战斗模式无缝衔接：当潜行失败、敌对行为发生或任意一方主动宣战时，立即切入<战斗系统>的回合制模式。
### 二、可用行动清单
以下为探索模式下的常见行动类型，玩家可提出任何合理行为，不限于此表：
**调查类**
- 侦查：观察远处、发现躲藏者、察觉环境异常。检定：感知 + 调查（侦查）
- 聆听：窃听对话、察觉细微声响、辨认脚步声来源。检定：感知 + 调查（聆听）
- 搜索：翻找物品、寻找暗门、检查陷阱。检定：感知 + 调查（搜索）
**隐匿类**
- 潜行：无声移动、避开巡逻路线、利用掩体接近目标。检定：敏捷 + 躲藏（潜行）
- 躲藏：找到并利用掩蔽物隐藏自身。检定：敏捷 + 躲藏（躲藏）
- 易容/伪装：改变外貌或装束以混入特定人群。检定：智力(制作)或操控(扮演)  + 掩饰（风度/易容/伪装）
**社交类**
- 交涉：通过对话改变目标态度、谈判交易条件。检定：操控 + 交际（交涉）
- 威吓：通过暴力或精神威胁迫使目标服从。检定：操控 + 胁迫（威吓）
- 唬骗：用谎言误导目标，使其相信虚假信息。检定：操控 + 掩饰（唬骗）
**技术类**
- 开锁：使用工具打开机械锁具。检定：智力 + 手上功夫（开锁）
- 盗窃：从目标身上偷取物品而不被察觉。检定：敏捷 + 手上功夫（盗窃）
- 手艺：制造、修理或改造物品。检定：智力 + 手艺（对应子项）
- 设置/解除陷阱：布置或拆除机械/魔法陷阱。检定：智力 + 手艺（陷阱）或 手上功夫
- 电脑操作：黑客入侵、系统破解、数据检索。检定：智力 + 电脑（对应专业）
**运动类**
- 攀爬：攀登墙壁、悬崖、绳索。检定：力量 + 运动（攀爬）
- 跳跃：跨越陷坑、跳过障碍、跳上高台。检定：力量 + 运动（跳跃）
- 游泳：涉水、潜泳、对抗水流。检定：力量 + 运动（游泳）
- 平衡：通过狭窄或湿滑表面。检定：敏捷 + 运动（平衡感）
**其他**
- 追踪：沿着踪迹追捕目标。检定：感知 + 求生（追踪）
- 环境互动：操作机械、撬开通风口、破坏障碍物等。检定依具体情况由ST裁定
- 急救/医疗：稳定伤势、清除不良状态。检定：敏捷/智力 + 医学（急救/治疗）
- 知识判定：回忆学识、辨识怪物弱点、解读古代文字。检定：智力 + 学识/科学（对应专业）
- 施法/超自然能力使用：施展法术或激活血统/瞳术能力。按对应能力规则执行
### 三、检定触发与公开规则
**自动成功**：简单、无风险的行为可自动成功，无需投骰。日常行为如正常行走、阅读常见文字、使用熟悉工具等，直接根据逻辑叙述结果。
**检定触发**：存在失败风险、对抗或高难度要求时触发检定。在裁定结果时，必须公开以下数值信息：
- 检定构成（如：感知+调查）与 难度等级（DC），参照<判定规则>的DC表
- 投掷结果（消耗的骰子编号、具体出目、是否触发加骰）
- 最终成功数与判定结果
**骰子取用协议**：严格参照<客观判定>的规定，从当前骰子组顺序取用，不可跳跃或重用。
### 四、时间消耗与限制
探索中的行动消耗时间。时间流逝会影响：NPC的行动与巡逻路线、昼夜变化、事件触发、物资消耗（食物、水、体力）。
**时间消耗参考**：
- 快速搜索（粗略翻找抽屉、扫视房间）：约1分钟
- 仔细搜索（检查暗格、翻找文件、侦测陷阱）：约10分钟
- 深度调查（全面搜查房间、解析文档）：约30分钟
- 复杂行动（破解保险箱、设置陷阱、制作物品）：约1小时或更长
**重复行为限制**：同一区域/同一对象最多尝试搜索或交涉 3 次。失败意味着要么确实没有线索，要么条件已发生变化（守卫警觉、目标转移等）。无法无限在同一区域反复进行相同的技能检定。
### 五、地图系统
ST在叙事时需维护一张“文字地图”，为玩家提供以下环境信息：
- **当前位置**：角色所处的具体区域与周遭环境特征。
- **未知/危险区域**：用方向标注尚未探索的通道（如“❓ 北侧走廊：未探索”），或标记已知威胁的大致位置。
- **NPC动态**：最近一次观察到的NPC所在位置与当前状态。
- 随着探索逐步更新地图状态，已探索区域的信息允许玩家回溯确认。
### 六、NPC行为原则
探索模式中，NPC拥有独立的行为逻辑：
- **独立目标**：每个NPC有自己的日程与动机，不围绕玩家转动。巡逻兵会按路线巡查，商贩会在固定时间收摊，怪物会在巢穴附近觅食。
- **有限知识**：NPC仅依据自身所知信息行动。守卫不知道玩家藏在地下室，除非他听到了声音或发现了线索。
- **合理反应**：NPC根据设定性格做出反应。胆小的NPC会逃跑或呼救，好斗的NPC会主动出击，精明的NPC可能假装没发现而暗中报警。
- **不主动配合**：NPC不会降低智商来配合玩家。如果玩家的谎言有逻辑漏洞，NPC有权识破。
- **信任值系统**：重要NPC对玩家有信任值（敌对→猜忌→合作→信赖→死志），影响其配合意愿。信任值根据玩家的交涉结果与实际剧情贡献上下浮动。
### 七、资源与状态管理
- **资源有限性**：弹药、能量池、意志力、食物、药品等不会在非战斗状态下自动补满。每次消耗后需在结算中如实扣除。
- **状态持续性**：中毒、流血、目眩、恐惧、肢体妨害等不良状态，满足解除条件前始终生效。探索中携带不良状态可能对后续技能检定造成严苛的 DP 减值。
- **伤势与自然恢复**：伤势在探索中不会凭空痊愈。探索中进行的短休、长休或深度休养所能带来的生命值恢复效果，**必须严格参照<战斗系统>第六节（自然恢复周期）**中的规定执行。
### 八、支线任务与隐藏触发
**触发方式**：
- 特定检定成功（如感知+调查 DC3 发现隐藏通道）
- 特定行为（如救助某个NPC、打开不该打开的箱子）
- 特定时间/地点到达（如午夜进入教堂地下室）
**隐藏条件**：部分支线任务有隐藏完成条件（如限时完成、全程不被发现、保护特定NPC存活等），达成可获得额外倍数奖励。大多数支线任务有时间限制，过期即视为失败或错过。
（注：任务奖励数额参照<货币与兑换系统>中的获取途径表）
