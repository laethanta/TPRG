## 战斗系统
### 一、进入战斗与先攻
当敌对行为发生、潜行失败或任意一方主动宣战时，立即切入回合制战斗模式。
**先攻判定**
- 所有参战单位投 `1D20 + 敏捷 + 沉着` 计算先攻值
- 按先攻值从高到低排列行动顺序
- 先攻值相同时，沉着较高者先动；沉着相同则敏捷较高者先动
- 先攻判定*不视为检定*，不受任何增加DP或检定结果的能力影响
**突袭轮**
- 若一方在战斗开始前未被察觉，发起者获得突袭轮
- 突袭轮中，能行动的单位只能进行*一个移动动作*或*一个标准动作*或*一个迅捷动作*
- 无法行动者视为失去所有闪避与洞察防御的措手不及状态。
### 二、行动资源
每单位在自己的回合内拥有以下动作资源，不可叠加或借贷至下一轮：
| 动作类型 | 每轮数量 | 说明 |
|:---|:---:|:---|
| 标准动作 | 1次 | 进行一次攻击、施展法术/特殊能力、使用物品、全力防御等 |
| 移动动作 | 1次 | 移动不超过速度的距离、拔武器、换弹匣、格挡、拾取物品等 |
| 迅捷动作 | 1次 | 取小件物品、拉动枪栓、开启特定装置等 |
| 反射动作 | 1次/轮 | 借机攻击、格挡、闪避等反应行为（需拥有对应能力） |
| 自由动作 | 不限 | 说话、松开武器、踢开障碍物等 |
**动作单向转化**：标准动作可转化为移动动作；移动动作可转化为迅捷动作。不可反向转化。
### 三、攻击判定流程
每次攻击需依次经过以下步骤：
**第1步：确定攻击模式与DP**
| 攻击方式 | DP构成 |
|:---|:---|
| 近战肉搏 | 力量 + 肉搏 + 天生武器伤害 - 目标防御 |
| 近战白刃 | 力量 + 白刃 + 武器伤害 - 目标防御 |
| 远程枪械 | 敏捷 + 枪械 + 武器伤害 - 目标防御 - 距离减值 |
| 远程弓箭 | 敏捷 + 弓箭 + 武器伤害 - 目标防御 - 距离减值 |
| 投掷武器 | 敏捷/力量 + 运动 + 武器伤害 - 目标防御 - 距离减值 |
| 施法攻击 | 智力 + 神秘学 + 法术威力值 - 目标防御 |
**第2步：投掷骰池**
- 根据DP投掷对应数量的D10，按<判定规则>的成功条件（8/9/10为成功）与加骰规则执行
**第3步：计算最终成功数**
- *最终成功数 = 投掷成功数 + 攻击附加成功 - 目标防御附加成功*
- 若最终成功数 ≤ 0，则为*未命中*
**第4步：伤害结算**
- 每1点最终成功数造成1点伤害
- 伤害类型由攻击方式决定（冲击B / 严重L / 恶性A）
- *伤害上限 = 武器伤害 + 关键属性 + 关键技能*（远程枪械为 武器伤害×2 + 枪械技能）
- 若最终成功数超过该上限，溢出部分无效，只造成上限数值的伤害。
**第5步：防御方减伤结算**
按以下顺序依次应用减伤能力：
1. 伤害免疫（若适用）
2. 伤害忽略
3. 物品硬度（若是攻击物品）
4. 伤害吸收
5. 伤害转化
6. 能量抗力 或 伤害减免（DR）
7. 伤害抵消
**第6步：生命值变动（伤势填充法则）**
根据最终造成的伤害类型与角色当前生命状态，按以下规则填入生命槽：
- *冲击伤害（B）*：优先扣除完好HP。若无完好HP，新受到的1点B伤会将已有的1点B伤恶化为L伤。
- *严重伤害（L）*：优先扣除完好HP。若无完好HP，新受到的1点L伤会将已有的1点L伤恶化为A伤。
- *恶性伤害（A）*：优先扣除完好HP。若无完好HP，新受到的1点A伤会将已有的1点B伤直接恶化为A伤；再无B伤则将L伤恶化为A伤。
### 四、防御构成
**目标防御由多项叠加**：
- *基础防御* = 敏捷与感知取低
- *闪避防御* = 传奇敏捷 + 专长 + 特殊能力
- *洞察防御* = 传奇感知 + 特殊能力
- *格挡防御* = 肉搏/白刃技能等级（需主动宣告使用，消耗移动动作）
- *盔甲防御* = 穿戴的盔甲防具
- *盾牌防御* = 持用的盾牌
- *天生防御* = 血统/改造/生物特性
**防御附加成功** = 传奇敏捷 + 传奇感知 + 其他来源。（在攻击检定前生效，直接等比抵消攻击方的投掷成功数）。
**多次受击破防惩罚**：
同一回合内每承受1次攻击，守方格挡防御 -1。格挡归零后扣减闪避防御，闪避归零后扣减基础防御。（此减值在战斗结束，或守方本人消耗相应动作清零）。
### 五、特殊战斗动作
| 动作 | 消耗 | 说明 |
|:---|:---|:---|
| 全力攻击 | 标准动作 | 本次攻击获力量值一半的增强加值（不超过基础防御），同时失去等额基础防御1轮 |
| 冲锋攻击 | 整轮动作 | 移动后攻击，每移动1米获得1DP增强加值（不超过力量值），基础防御相应降低 |
| 全力防御 | 标准动作 | 闪避防御获得基础防御的加值，对抗范围伤害的反射豁免获等额加值 |
| 肉搏格挡 | 移动动作 | 防御获得等同于肉搏技能等级的格挡加值 |
| 白刃格挡 | 移动动作 | 防御获得等同于白刃技能等级的格挡加值 |
| 摔绊 | 近战攻击 | 接触命中后进行对抗，胜出则目标倒地 |
| 冲撞 | 近战攻击 | 对抗后击退或击倒目标 |
| 擒抱 | 近战攻击 | 接触命中后进行对抗，胜出则擒抱目标 |
| 虚招 | 标准动作 | 智力+掩饰 对抗 感知+感受，胜出则目标失去基础防御和闪避防御 |
| 瞄准 | 全回合动作 | 下一轮攻击获得1DP瞄准加值+1伤害上限，最多累加5轮 |
### 六、伤害类型与生命值
**生命值上限** = 耐力 + 体积 + 传奇耐力加值
**伤势恶化与濒死**：
- 当角色不再有“完好”生命值，且最坏状态为严重伤害（L）时，角色陷入昏迷，直到恢复1点完好HP或受到外界有效刺激。
- 当角色最坏状态为恶性伤害（A）时，进入濒死状态。每轮结束有1点非A生命值自动转化为A，直至全部为A或恢复1点完好。
**死亡判定**：
- 杂兵与普通NPC：HP归零直接死亡或被摧毁。
- 玩家与关键角色：当所有生命值全部恶化变为恶性伤害（A）时，彻底死亡。
**自然恢复周期**：
| 休息类型 | 恢复效果 |
|:---|:---|
| 短休息（15分钟） | 1点冲击伤害（B）→ 完好；可选择一种不良状态获得一次豁免机会 |
| 长休息（8小时） | 恢复1点意志力；非战斗状态下睡眠 |
| 深度休养（24小时） | 1点严重伤害（L）恢复为完好 |
| 极效休养（7天） | 1点恶性伤害（A）恢复为完好，或恢复1点属性伤害 |
### 七、环境与战术修正
以下修正以DP加值/减值或特定效果的形式影响战斗：
| 修正类型 | 效果 |
|:---|:---|
| 高地优势 | 近战攻击+1~2DP；远程攻击+2DP |
| 掩蔽 | 少许掩蔽+2掩蔽防御，部分+4，大量+8，完全掩蔽无法被攻击 |
| 倒地目标 | 近战攻击对其防御-2环境减值；远程攻击对其防御+2环境加值 |
| 措手不及 | 失去基础、闪避、洞察与格挡防御，不能使用反射动作  |
| 困难地形 | 移动1米消耗2米移动力；禁止进行冲锋 |
| 照明不足 | 视距减半。处于完全黑暗中则强制进入目盲状态 |
### 八、战斗结束与资源结算
- 战斗脱离判定结束后，所有资源消耗（弹药、能量池、消耗品、意志力）*不会自动补满*。
- 战斗中积累的不良状态点数（流血、冻结、剧痛等）将持续存在，直到满足解除或豁免条件。
- 伤势必须通过自然恢复周期、医疗技能判定或返回主神空间花费奖励点来治疗。
- 状态规则详见<状态与生理反馈系统>
