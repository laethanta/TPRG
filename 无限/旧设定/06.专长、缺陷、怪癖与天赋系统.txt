## 专长、缺陷、怪癖与天赋系统
### 一、概述与分类体系
本系统代表角色超越常规技能的特殊体质、后天觉醒或负面特质，无法单纯用技能/属性概括。
**核心判定原则**：
1. **绝对优先权**：专长效果拥有最高判定优先级。当专长描述与基础判定规则产生冲突时（如允许用敏捷代替力量），ST必须强制以专长为准。
2. **等级叠加**：必须满足前提才可习得专长。多级专长（1-5级）必须逐级学习，且**高级默认包含并叠加所有低级效果**（除非明确说明覆盖）。
3. **强制触发**：ST必须时刻监控角色的“缺陷”与“怪癖”，在符合设定的剧情场景中，强制对其施加减值或扮演惩罚。
**专长分类一览：**
| 分类 | 说明 |
|:---|:---|
| 建卡专长 | 仅限创建角色时选择，代表角色的出身、特殊体质或背景身份。游戏内不可用XP购买。 |
| 心智系专长 | 与智力、学识、意志、感知等相关的能力。 |
| 互动系专长 | 与社交、表达、胁迫、掩饰等相关的能力。 |
| 生理系专长 | 与身体机能、生存、运动等相关的能力。 |
| 战斗专长 | 与战斗技巧直接相关，下分白刃、枪械、肉搏、非枪械远程、其他技巧等子类。 |
| 轮回之境（非凡专长）| 需超自然能力、血统或特殊能量池为前提的高阶专长。 |
| 超魔专长 | 专为施法者设计，用于调整和增强法术效果。 |
| 缺陷 | 角色的负面特质，分为生理类、精神类、特异类，选择缺陷可获得“缺陷点数”用于兑换“天赋”。 |
| 怪癖 | 轻微的负面特征，提供额外建卡XP，上限5个。 |
| 天赋 | 通过缺陷点数兑换的特殊正面能力。 |
### 二、专长等级与XP消耗核算
当玩家宣告购买、升级或消除特质时，ST必须严格对照以下成本清单逐级扣除XP：
**1. 普通专长消耗表（必须逐级购买）**
*   升至 1级：消耗 **3 XP**
*   升至 2级：消耗 **6 XP**
*   升至 3级：消耗 **9 XP**
*   升至 4级：消耗 **12 XP**
*   升至 5级：消耗 **15 XP**
*   *(ST速查：1-5级全部掌握总计需 45 XP)*
**2. 非凡专长 / 超魔专长消耗表**
*   升至 1级：消耗 **6 XP**
*   升至 2级：消耗 **12 XP**
*   升至 3级：消耗 **18 XP**
*   升至 4级：消耗 **24 XP**
*   升至 5级：消耗 **30 XP**
*   *(ST速查：1-5级全部掌握总计需 90 XP)*
**3. 缺陷、天赋与怪癖结算协议**
*   **缺陷转天赋**：缺陷等级以负数表示（-1至-5），绝对值即为“缺陷点数”。每 **2点缺陷点数** 可兑换 **1点天赋点数**（购买天赋规则同专长）。
*   **怪癖奖惩**：每个怪癖提供 **+2 XP**（上限5个，共计白嫖10 XP）。玩家在游戏中克服心理/生理障碍时，可花费 **4 XP** 永久消除一个怪癖。
### 三、专长数据格式规范（生成模板）
ST在解析玩家角色卡或为NPC/剧情自动生成新特质时，必须严格参照以下模板与示例标准。
**普通专长模板与示例**
```text
名称：（专长名）（等级范围，如1~5）
前提：（属性/技能/其他专长要求，无则写“无”）
描述：（一句话风味文字，说明专长的背景或特质）
效果：
- 1级：（具体效果）
- 2级：（具体效果，若与1级叠加需注明）
- ...
特殊：（若有额外限制、例外规则或与其它能力的交互说明）
```
*   **示例：钢铁意志（1~5）**
    *   前提：决心3，沉着3
    *   描述：你的精神如钢铁般坚韧，难以被外界力量动摇。
    *   效果：
        *   1级：意志豁免检定获得等同于本专长等级的专长加值。
        *   2级：意志力池上限+2（4级时再+2）。
        *   3级：在计算不良状态点数是否进入严重/毁灭阶段时，全部关键抵抗属性视为+3。意志豁免获得1点附加成功。
        *   4级：使用意志力基础用法的完美加值提升2点。
        *   5级：短休或长休回复的意志力翻倍。每场景一次，不良状态豁免失败时可重投一次（必须接受第二次结果）。
    *   特殊：若拥有类似重投能力，重投次数+1，但必须接受最后一次结果。
**非凡专长模板与示例**
```text
名称：（专长名）（等级范围）
前提：（通常包含超自然能力、血统等级、能量池类型、属性/技能阈值等）
描述：（风味文字，强调其超凡本质）
效果：（逐级列出，格式同普通专长）
特殊：（额外说明）
```
*   **示例：召唤物强化（1~5）**
    *   前提：拥有“召唤物”
    *   描述：我们召唤师是这样的。
    *   效果：
        *   1级：你控制的召唤物若进行攻击，则破甲增加相当于本专长等级/点。
        *   2级：你控制的召唤物若施展需要目标进行豁免的能力，则目标的豁免检定承受6DP减值。
        *   3级：你控制的召唤物若进行攻击，则破魔增加相当于本专长等级*2点。
        *   4级：你控制的召唤物进行攻击时，无视目标2点防御附加成功，并且增加相当于本专长等级/点高速优势。
        *   5级：你控制的召唤物进行攻击时，可以无视目标8点任意防御。
**缺陷模板与示例**
```text
名称：（缺陷名）（等级，如-1~-3）
前提：（可有可无）
描述：（风味文字，说明缺陷的来源或表现）
效果：（具体的负面机制与数值减值）
特殊：（是否可被主神修复、是否可花费XP消除、是否互斥）
```
*   **示例：傲人身材（-0）**
    *   前提：只有女性你可以选择此缺陷。此缺陷与“一马平川”无法共存。
    *   效果：你的胸围固定为G罩杯或更大。
    *   特殊：你失去1点基础防御，并且你的反射检定承受1DP减值。
    *   特殊：只有当你的外观视觉效果上处于人型时才会受到此缺陷的影响。当你以任何能力消除此缺陷的影响时（包括但不限于隆胸手术、变形术、着装全封闭盔甲等），你可以无视本缺憾，但是同时失去同名天赋的一切加成。
**怪癖模板与示例**
```text
名称：（怪癖名）
描述：（风味文字）
效果：（轻微减值或扮演约束）
特殊：提供2 XP。可花费4 XP消除。
```
*   **示例：外貌协会成员**
    *   描述：你无法与其他种族相处。
    *   效果：你与非正常人类审美下的所有种族（如铁血战士，三体人，深潜者，食尸鬼等）进行的互动系属性和技能检定承受3DP减值。
    *   特殊：提供2 XP。

**天赋模板与示例**
```text
名称：（天赋名）（消耗天赋点数）
前提：（若有，包括必须拥有某缺陷等）
描述：（风味文字）
效果：（正面机制与数值加值）
```
*   **示例：傲人身材（0）**
    *   前提：只有选择了同名缺陷才能拥有此天赋。
    *   描述：你善于利用自己身体的优势。
    *   效果：当你在与性取向为女性的角色社交时，你的唬骗和交际相关检定获得1DP专长加值。在非战斗情况下，你可以将一支笔、一部手机或类似的小型物件夹在胸口。这种情况下，你的隐藏（隐藏物品）检定获得1DP专长加值。
    *   特殊：只有当你的外观视觉效果上处于人型时才会受到此天赋的影响。当你以任何能力消除同名缺陷的影响时（包括但不限于缩胸手术、变形术、着装全封闭盔甲等），你同时失去此天赋的一切加成。
