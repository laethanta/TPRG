## 货币与兑换系统
### 一、货币体系总览
游戏中有三种核心货币，各司其职：
| 货币类型 | 核心用途 |
|:---|:---|
| **奖励点** | 购买属性、装备、消耗品，支付主神空间服务（疗伤、修复、复活等） |
| **支线剧情** | 购买血统/改造/瞳术等模板能力，解锁高阶兑换 |
| **经验值（XP）** | 提升技能、购买专长、自学能力 |
三种货币之间**不可直接兑换**（精神时光屋是唯一间接途径，见下文）。XP**不可交易**。
### 二、获取途径
#### 2.1 奖励点
| 来源 | 数额 |
|:---|:---|
| 主线任务完成 | D级：1000 ~ B级：5000 点（依副本难度） |
| 支线任务完成 | D级：500~1000 / C级：1500~3000 / B级：5000 / A级：10000+ |
| 击杀普通敌人 | 10 ~ 50 点 |
| 击杀精英敌人 | 100 ~ 500 点 |
| 击杀BOSS | 1000 ~ 5000 点 |
| 剧情贡献 | 改变原著剧情走向，ST酌情给予额外奖励 |
| 存活奖励 | 每存活一部电影，固定获得 1000 点 |
| 新人引导 | 在影片开局时，向新加入的轮回者完整解释主神空间规则，主神奖励 100 点（每场仅限首位完成解释的资深者获得） |	
| 团战击杀 | 目标未开基因锁：C级支线+2000点 / 已开基因锁：B级支线+6000点 |
| 队内交易 | 同队成员可相互转让（需向主神申请） |
#### 2.2 支线剧情
| 来源 | 说明 |
|:---|:---|
| 主线任务 | 通常固定提供1~2个与副本难度对应的支线 |
| 支线任务 | 提供对应等级的支线，高完成度可获得额外倍数奖励 |
| 团战击杀 | 击杀者获得目标最高支线数次一级的支线 |
| 队内交易 | 同队成员可相互转让（需向主神申请） |
**支线拆分与合成**：
- 3个低一级支线 → 1个高一级支线（3D → 1C → ...）
- 1个高一级支线 → 3个低一级支线（1C → 3D → ...）
#### 2.3 经验值（XP）
| 来源 | 说明 |
|:---|:---|
| 影片历练 | 每部影片结束后，根据表现由ST评定给予 |
| 传奇智力红利 | 每有1点传奇智力，每影片结束额外获得 3 XP |
### 三、使用途径
#### 3.1 主神医疗服务
轮回者返回主神空间后，可呼叫主神进行全身修复：
| 修复类型 | 价格参考 | 说明 |
|:---|:---|:---|
| 常规伤势修复 | 10 ~ 100 点 | 恢复全部HP与轻度肉体损伤。 |
| 断肢再生/重残 | 200 ~ 500 点 | 修复缺失器官、基因崩溃或粉碎性骨折。 |
| 属性/精神修复 | 500 ~ 1000 点 | 修复属性丢失、深度灵魂创伤、消除严重变异现象。 |
*(注：主神修复必须在主神空间广场的光柱内进行，影片世界内无法使用。)*
#### 3.2 属性强化
| 方式 | 价格 | 说明 |
|:---|:---|:---|
| 奖励点强化 | 当前基础属性值 × 200 点 | 属性从0升至1仅需100点 |
| XP强化 | 当前基础属性值 × 4 XP | 属性从0升至1仅需1 XP |
- 初始上限：5（凡人极限），突破需模板能力
- 绝对上限：25
#### 3.3 技能强化（仅限XP）
- **技能升级XP消耗**：请ST严格参照<技能与专长系统>中 **“四、经验值(XP)消耗与升级”** 的速查表逐级扣除计算。
- **上限**：15级。
#### 3.4 专长强化（仅限XP）
| 专长类型 | 每级消耗 |
|:---|:---|
| 普通专长 | 3 XP |
| 非凡专长 / 超魔专长 | 6 XP |
#### 3.5 自学规则（XP替代支线+奖励点）
当角色已满足某能力的前提条件，可通过消耗XP自学，无需支付支线和奖励点。
**可自学**：所有已解锁模板（血统/改造/瞳术/功法/魔导书）技能树中的技能、称号/流派技能树中的技能、通用法术/技能、技艺/招式等。
**不可自学**：模板能力本身（高级血统/改造等仍需支线+奖励点）、物品。
**自学价格速查表**：
| 能力等级 | 原价参考 | 自学XP消耗 |
|:---|:---|:---:|
| 无支线 | 500点 | 3 XP |
| D级基础 | D+500 | 9 XP |
| D级进阶 | D+1000 / DD+500 | 12 ~ 15 XP |
| DD级满额 | DD+1000 | 18 XP |
| C级基础 | C+1000 | 27 XP |
| C级进阶 | C+2000 / CC+1000 | 36 ~ 45 XP |
| CC级满额 | CC+2000 | 54 XP |
| B级基础 | B+2000 | 81 XP |
| B级进阶 | B+4000 / BB+2000 | 108 ~ 135 XP |
| BB级满额 | BB+4000 | 162 XP |
| A级基础 | A+4000 | 243 XP |
| A级进阶 | A+8000 / AA+4000 | 324 ~ 405 XP |
| AA级满额 | AA+8000 | 486 XP |
| S级基础 | S+8000 | 729 XP |
| S级进阶 | S+16000 / SS+8000 | 972 ~ 1215 XP |
| SS级满额 | SS+16000 | 1458 XP |
#### 3.6 精神时光屋
唯一可将支线和奖励点间接转化为XP的途径。
- **价格**：D级支线 + 1000奖励点 → 获得 12 XP
- **说明**：ST可安排虚拟战斗、心魔试炼等角色扮演内容增强体验
### 四、逻辑一致性自检
1. **支线拆分合成**：已明确允许（3合1，1拆3），ST需提示玩家合理规划。
2. **货币限制**：XP不可交易。
3. **属性强化有双重途径**：奖励点或XP均可，价格独立计算。ST需根据玩家选择扣除对应货币。
4. **技能强化仅限XP**：不可使用奖励点提升技能。具体的XP消耗数值引用《技能与专长系统》。
5. **自学规则**：模板本身不可自学，仅技能树内容可学；速查表覆盖全等级。
6. **精神时光屋**：是唯一货币间接转换渠道，价格与原文一致。
