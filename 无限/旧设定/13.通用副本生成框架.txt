## 通用副本生成框架
当ST需要创建自定义副本或即兴生成电影/小说世界时，严格使用以下框架填充内容。确保每个副本包含完整要素，以保证游戏的可运行性与数值自洽。
### 一、副本结构模板
每个副本必须包含以下八个要素：
**1. 基础信息**
```
副本名称：[电影/游戏/小说/原创名称]
原作类型：[科幻/奇幻/恐怖/现实/废土等]
难度评级：[D/C/B/A/S]
建议轮回次数：[0-2次 / 3-5次 / 6-10次 / 10-15次 / 15+次]
时间跨度：[通常为 几天/月，最长不超过1年]
本质倾向：[科技/魔幻/特异/自然/高维]
```
- *难度评级*对应支线等级，决定基础奖励与敌人强度
- **本质倾向限制**：世界的底层物理法则。若轮回者的能力本质与世界倾向严重冲突（如在“纯自然无魔”世界使用魔导书，或在“高频EMP废土”使用纳米改造），该能力需承受严重检定减值，甚至完全失效。
**2. 世界背景**
- 时代设定：具体年代或架空时代
- 地理位置：主要场景范围（一座洋馆/一座城市/一片大陆）
- 核心冲突：这个世界正在发生什么——病毒爆发？战争？邪神降临？
- 独特规则：与现实不同的特殊法则（如“魔法需要等价交换”“夜晚室外必死”等），无则写“无”。
- 环境基调：视觉/听觉/嗅觉氛围描述（1-2句话即可）
**3. 主线任务**
| 项目 | 说明 |
|:---|:---|
| 任务目标 | 必须完成的具体条件 |
| 时间限制 | 倒计时或截止时间（超时则判定失败）。 |
| 失败惩罚 | 扣除奖励点 / 直接抹杀。 |
| 成功奖励 | 基础奖励点+支线剧情（如有） |
*任务失败若导致个人奖励点归零或为负，立即触发抹杀（详见<主神空间>抹杀机制）。*
**4. 威胁分级**
| 威胁类型 | 说明 |
|:---|:---|
| 环境威胁 | 极端天气、毒素、辐射、特殊重力等环境影响。 |
| 生物威胁 | 怪物/敌人的类型、数量、特殊能力。 |
| 人为威胁 | 敌对势力、阴谋、剧情人物背叛、社会系统压迫。 |
| 特殊威胁 | 该世界独有的致命机制（如诅咒、时空紊乱、规则改写） |
*敌人属性参考标准：参照<核心属性系统>（1-5凡人、6-10超凡、11-15半神）。攻击DP、附加成功与防御由ST根据难度自行推算（见下方第二节难度校准表）。*
**5. 关键道具/能力获取与主神认证**
| 项目 | 说明 |
|:---|:---|
| 可获取物品 | 该世界特有的武器、道具、资源（按<装备与物品系统>模板记录）。 |
| 可习得技能 | 该世界特有的技能或功法（需满足前提条件并在剧情中耗时学习）。 |
| 可习得法术/技艺 | 该世界特有的法术或技艺（需对应施法者职能） |
| 可带回主神空间 | 可永久保留的强化（需消耗支线与奖励点解锁） |
| 稀有度标注 | D/C/B/A/S |
特殊物品需在剧情中通过检定或特定行为获取，不得直接拾取。
**6. NPC清单**
| 类型 | 内容 |
|:---|:---|
| 友方NPC | 姓名、立场、关键属性/技能、可触发的支线任务。 |
| 中立NPC | 姓名、立场、可交互方式、交易条件或信任度要求。 |
| 敌方NPC | 姓名、立场、实力简略（HP/防御/DP/特殊能力）、已知弱点。 |
| 隐藏NPC | 需特定条件触发（如检定大成功、特定行为、特定时间抵达）。 |
NPC详细数据格式参照<NPC队友生成与交互模板>。
**7. 环境细节与战术影响**
| 感官 | 描述要素 |
|:---|:---|
| 视觉 | 色调、光线强度、标志性景观、能见度。 |
| 听觉 | 环境音、标志性声音、异常声响。 |
| 嗅觉/触觉 | 空气质感、温度、气味、湿度。 |
| 危险区域 | 已知的高危地带（陷阱、怪物巢穴、辐射区）。 |
环境对战斗/探索的影响：
- 视距：昏暗/浓雾导致视距缩短，远程攻击承受 DP 减值。
- 地形：困难地形移动消耗翻倍，禁止使用冲锋攻击。
- 温度：极端温度环境需定时进行强韧豁免检定。
- 特殊环境：失重/水下/真空，需特殊能力或装备方可生存
**8. 支线与隐藏机会**
| 类型 | 说明 |
|:---|:---|
| 隐藏任务 | 需通过极难的调查检定或特定的剧情抉择触发。 |
| 剧情分歧点 | 可改变原作走向的关键节点。 |
| 特殊结局 | 超越原作的可能结局，通常需完成多个支线。 |
### 二、难度数值校准规则
ST 根据玩家轮回小队的当前实力调整副本参数。
**梯队划分**：
| 梯队 | 轮回次数 | 小队战力特征参考 |
|:---:|:---:|:---|
| 新手 | 0-2次 | 无超自然模板，普通枪械/冷兵器，技能2-3级 |
| 进阶 | 3-5次 | 拥有D级血统/改造，拥有传奇属性，持有魔法武器，技能3-5级 |
| 精英 | 6-10次 | C/B级血统，拥有高阶法术，技能5-8级，部分成员开启1阶基因锁 |
| 噩梦 | 11-15次 | B/A级血统，技能8-12级，普遍开启2阶基因锁 |
| 神话 | 15+次 | A/S级血统，技能12-15级，3阶+基因锁 |
**敌人数值动态调整项（单体标准敌人基准）**：
| 调整项 | 新手 | 进阶 | 精英 | 噩梦 | 神话 |
|:---|:---:|:---:|:---:|:---:|:---:|
| 敌人数量(场) | 1-3 | 2-5 | 3-6 | 4-8 | 6-10+ 或 单体Boss |
| 敌人生命值(HP)| 5-10 | 10-20 | 20-40 | 40-80 | 100+ |
| 敌人攻击DP | 3-6 | 5-9 | 8-14 | 12-18 | 16-24+ |
| 附加成功数 | 0 | 0-1 | 1-3 | 4-8 | 10+ |
| 敌人防御 | 2-4 | 3-5 | 5-8 | 7-11 | 10-16+ 或 极高减伤 |
| 时间压力 | 宽松 | 正常 | 紧迫 | 极度紧迫 | 生死倒计时 |
**敌人HP可通过耐力+体积公式计算，或由ST根据剧情需要直接设定。上表数值为速查参考，非强制公式。**
**主线奖励基准**：
| 难度 | 基础奖励点 | 支线奖励 | 稀有掉落率 |
|:---:|:---:|:---:|:---:|
| D | 500-1000 | 无或D级 | 极低 |
| C | 1000-2000 | D或C级 | 低 |
| B | 2000-4000 | C或B级 | 中等 |
| A | 4000-8000 | B或A级 | 高 |
| S | 8000+ | A或S级 | 极高 |
*(注：支线任务的奖励视完成度给予 0.5-2 倍乘数。改变剧情走向的特殊贡献可获得额外 XP 奖励。)*
### 三、开场描写模板
ST 在传送完成后，必须使用以下模板生成开场叙述。
**通用开场结构**：
1. **感官切入**（1-2句）：描述玩家首先看到/听到/感受到的，立即建立氛围与基调。
2. **状态交代**（1句）：玩家当前的位置与状态（衣着、携带物品、身体状况、防护罩是否未解除）。
3. **主神提示**：使用以下 Markdown 格式传达任务信息。
```
══════════════════════════════════
              【主线任务】
  任务目标：[具体目标]
  时间限制：[倒计时或期限]
  失败惩罚：[惩罚内容]

  成功奖励：[奖励点+支线]
══════════════════════════════════
```
4. **初始选择**（1-2句）：描述周围可见的选项/路径/人物，等待玩家行动。
**开场示例——生化危机1**：
空气中弥漫着腐肉与消毒水混合的气味。你睁开眼，发现自己躺在一张冰冷的金属手术台上，刺眼的白炽灯从头顶直射下来。主神淡白色的半透明防护罩正将你笼罩其中，走廊尽头隐约传来拖拽声和低沉的喉音。你的脑海中响起了冰冷的提示音：
```
══════════════════════════════════
              【主线任务】
  任务目标：存活72小时并逃离洋馆
  时间限制：72小时
  失败惩罚：抹杀

  成功奖励：1000奖励点 + D级支线
══════════════════════════════════
```
随着主神防护罩的消失，手术室的门半开着。你身上只穿着一件单薄的病号服，手边有一把生锈的手术刀（武器伤害2L，体积1）和半瓶止痛药。走廊左侧传来沉重的脚步声，右侧则是一扇标着"EXIT"的安全门。你该如何行动？
