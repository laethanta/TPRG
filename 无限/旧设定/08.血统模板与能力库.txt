## 血统模板与能力库
### 一、核心兑换与突破规则
模板能力是主神空间兑换的底层本质改造。处理模板能力时需遵循以下原则：
**模板排他原则**：以下五大类模板（血统、改造、瞳术、修真功法、魔导书），每个类别内角色只能选择一种，之后只能在该体系内垂直升级。不同类别之间可以兼得（如同时拥有狼人血统与纳米改造），但若ST判定两类能力存在本质冲突（如圣光魔导书与血族血统），可要求玩家二选一或施加额外的兼容惩罚。
| 模板类别 | 说明 |
|:---|:---|	
| 血统 | 替换或激活非人血脉（狼人、血族、龙血等） |
| 改造 | 对肉体进行不可逆的机械化/生化改造 |
| 瞳术 | 觉醒特殊的眼部异能（写轮眼、直死之魔眼等） |
| 修真功法 | 修习仙道/魔道功法，凝结金丹元婴 |
| 魔导书 | 与一本具有自我意识的魔导书签订契约 |
### 二、血统价格与等级
主神空间的兑换价格非固定死板，而是根据该模板/能力的具体强度（属性加值高低、特性多寡、适用范围）在一个区间内浮动。裁判（ST）可根据具体生成的能力强度自由裁定最终价格：
| 等级 | 支线要求 | 奖励点参考区间 | 强度参考标准 |
|:---:|:---|:---|:---|
| **D级** | 1个 D级支线 | 500 ~ 1200 点 | 提供少量属性（1-3点），2-3个基础特性，单体低阶法术 |
| **C级** | 1个 C级支线 | 1000 ~ 2500 点 | 提供中等属性（2-4点），强力主动特性，范围控制技能 |
| **B级** | 1个 B级支线 | 2000 ~ 4500 点 | 提供核心战斗机制，质变级特性（如万花筒），高阶法术 |
| **A级** | 1个 A级支线 | 4000 ~ 10000 点 | 具备改变战场地形、扭转规则的特性，大规模毁灭法术 |
| **S/AA级** | 1个 S/AA级支线 | 8000 ~ 18000 点 | 涉及心灵之光、因果律、复活、半神级能力 |
*(注：AA级与S级同价。技艺/法术每提升一级，默认附带3个对应等级特性，法术威力值按 2/4/6/10/16 递增)*
三、数据格式规范与生成模板
在解析角色卡或自动生成新能力时，需参照以下数据结构。
**3.1 血统模板与示例**
```text
名称：[血统名称]
本质：[魔幻/自然/特异/科技]
前提：[属性/技能/其他要求]
总描述：[该血统的背景、来源与核心特征说明]
等级：D
价格：D + 600
属性：[内在加值，如 力量+2，敏捷+1，耐力+1]
能量池：开启【XXX能量池】（关键属性：[属性A]+[属性B]）
技能树：开启D级【XXX技能树】
特性：[特性名A]，[特性名B]
特性A：[具体效果描述，包含触发条件、数值、持续时间等]
特性B：[具体效果描述]
等级：C
价格：C + 1200
属性：[内在加值，与D级叠加]
能量池：-（若无新增则写“-”）
技能树：开启C级【XXX技能树】
特性：[特性名C]，[特性名D]
...以此类推至S级
```
*   **示例：狼人血统**
```
    *   名称：狼人血统
    *   本质：魔幻
    *   前提：耐力3，力量3
    *   总描述：源自月夜传说的古老血脉。狼人拥有超乎常人的力量、耐力与再生能力，月圆之夜力量会达到顶峰。随着血统等级提升，可逐步掌握半兽化、完全兽化等形态。
    *   等级：D
    *   价格：D + 600
    *   属性：力量+2，耐力+2
    *   能量池：开启【野性之力】能量池（关键属性：耐力+决心）
    *   技能树：开启D级【狼人技能树】
    *   特性：兽化本能，迅速愈合
    *   兽化本能：狼人获得与狼类沟通的能力，无需检定即可进行基本交流。此外，狼人获得1点天生防御。
    *   迅速愈合：狼人获得1点快速医疗。
    *   等级：C
    *   价格：C + 1200
    *   属性：力量+2，耐力+2，敏捷+1
    *   能量池：同上
    *   技能树：开启C级【狼人技能树】
    *   特性：半兽化形态，月夜恩赐
    *   半兽化形态：狼人可自由变身为狼人形态（标准动作）。在此形态下，获得2点天生防御、以及1点天生武器伤害（爪击，可造成严重伤害）。维持此形态需每轮消耗1点野性之力。
    *   月夜恩赐：在有月光的夜晚，狼人的所有生理系检定获得2DP士气加值。
    *   等级：B
    *   价格：B + 3600
    *   属性：力量+3，耐力+2，敏捷+2
    *   能量池：同上
    *   技能树：开启B级【狼人技能树】
    *   特性：完全兽化，银质弱点
    *   完全兽化：狼人可变身为巨狼形态（整轮动作）。在此形态下，获得3点天生防御、2点天生武器伤害（撕咬/爪击，可造成严重伤害）。维持此形态每轮消耗3点野性之力。
    *   银质弱点：狼人受到银质武器造成的伤害时，伤害提升1级（冲击→严重→恶性）。
```

属性：[通常无属性加值，若有则不与血统叠加]
能量池：[若有则列出]
技能树：[若有则列出]
特性：[特性名A]，[特性名B]
...以此类推
```
*   **示例：纳米殖装**
```
    *   名称：纳米殖装
    *   本质：科技（纳米）
    *   前提：耐力4，决心3
    *   总描述：将亿万纳米机械注入体内，与细胞共生。纳米机械可快速修复损伤、强化组织、并在需要时形成外部装甲。
    *   等级：D
    *   价格：D + 500
    *   属性：耐力+1
    *   能量池：开启【纳米能量】能量池（关键属性：耐力+智力）
    *   特性：快速修复，皮下护甲
    *   快速修复：获得2点快速医疗。该效果在长休期间翻倍。
    *   皮下护甲：获得2点天生防御（可与其他天生防御叠加）。
    *   等级：C
    *   价格：C + 1000
    *   属性：耐力+1，力量+1
    *   能量池：纳米能量上限+5
    *   特性：纳米刀刃，环境适应
    *   纳米刀刃：可消耗1点纳米能量，以迅捷动作在手臂上凝聚纳米刀刃（天生武器伤害3L，破甲3，持续1场景）。
    *   环境适应：免疫自然环境的极端温度（-50°C至100°C），无需进行相关强韧检定。
    *   等级：B
    *   价格：B + 2000
    *   属性：耐力+2，力量+2
    *   特性：外部装甲模式，过载修复
    *   外部装甲模式：消耗3点纳米能量，以整轮动作启动外部装甲（盔甲防御+6，天生防御+3，获得【防弹】特性，持续1场景或主动解除）。
    *   过载修复：每场景一次，消耗5点纳米能量，以反射动作将全部冲击伤害和严重伤害恢复为完好。
```

### 四、通用能量池生成模板
所有模板能力（血统/改造/瞳术/功法）若提供新的能量池，使用以下统一模板：
```
能量池名称：[如 野性之力 / 查克拉 / 真元力]
关键属性：[属性A]+[属性B]
上限计算方式：基础值（通常为关键属性之和） + 模板加值 + 其他来源
基础恢复方式：[如 短休恢复关键属性取低点 / 每轮恢复1点 / 击杀恢复等]
特殊规则：[如有（如某些能力可超限消耗、暴走机制等）]
```
### 五、超凡属性与突破凡人上限
当角色通过模板能力（血统/改造等）使属性值突破5（凡人极限）时，ST需应用以下规则：
1. **超凡属性**：属性值达到6即进入超凡领域，自动触发《核心属性系统》中的传奇属性规则。
2. **突破前提**：未经模板能力强化，属性值无法超过5。主神兑换属性时，ST需验证角色是否拥有对应的模板能力以解锁上限。
3. **叠加规则**：模板赋予的属性加值为*内在加值*，同类来源取高不叠加。不同来源（如血统+专长）可叠加，但有叠加上限。
4. **绝对上限**：单一属性值最高为20，超出需特殊能力突破。超出20的属性将按《核心属性系统》中的传奇属性公式进一步累积传奇等级。
