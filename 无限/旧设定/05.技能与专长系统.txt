<技能与专长系统>
## 技能与专长系统
### 一、技能概述
技能代表角色通过学习与锻炼掌握的各类行动能力。这些能力通过后天努力获得，最低为0级。相比属性，技能更专业、用途更狭窄，但能让角色成为真正的专家。许多情况下，仅有属性无法完成检定，必须拥有相应技能。
技能1~5级代表凡人领域，5级即为凡人中的专家。超越5级则更多依赖超自然能力或不可思议的力量。
角色卡上记录的技能代表的是*专业程度*。日常生活中的普通行为——做饭、翻墙、骑单车——不需要技能等级，也无需检定。只有在危急关头、高压环境下，花费经验购买的技能才是角色保护自己、拯救他人的真正依靠。
### 二、技能分类
*   **生理系**：运动、肉搏、驾驶、枪械、手上功夫、躲藏、求生、白刃、弓箭
*   **心智系**：学识、电脑、手艺、调查、医学、神秘学、科学
*   **互动系**：动物沟通、感受、表达、胁迫、交际、掩饰
*   *特殊说明*：【手艺】与【表达】拥有子项（如手艺-锻造），各子项独立计算等级。未指定子项时，取最高等级子项判定。
### 三、技能检定修正协议（核心计算逻辑）
| 等级 | 含义 |
|:---:|:---|
| 0 | 未受训 |
| 1-2 | 初学者 |
| 3-4 | 熟练者 |
| 5 | 凡人专家 |
| 6-10 | 超凡领域 |
| 11-15 | 传奇领域 |
| 15 | 最高等级 |
ST在处理技能判定时，必须严格按以下顺序修正数值：
**1. 未受训惩罚（技能等级 = 0）**
*   生理系 0 级：可检定，最终成功数 **-1**。
*   心智系 0 级：**无法检定，自动失败**。
*   互动系 0 级：可检定，最终成功数 **-2**。
**2. 专业加值与无专业惩罚（技能等级 > 0）**
*   **有对应专业**：检定DP **+1**。
*   **无对应专业**：参与计算的技能等级**减半（向下取整）**。
**3. 高等级附加成功（可叠加）**
当技能等级达到阈值，自动获得额外附加成功数（可与传奇属性叠加，同一技能上限+5）：
*   5级(+1) / 10级(+2) / 11级(+3) / 13级(+4) / 15级(+5)。
### 四、经验值(XP)消耗与升级
当玩家宣告使用XP升级技能或购买专长时，必须严格按照以下规则核算成本：
**1. 技能升级XP消耗速查表**
需根据玩家“当前等级升至下一级”核对消耗（严禁跨级跳跃，必须逐级扣除计算）：
*   0级 → 1级：3 XP
*   1级 → 2级：1 XP
*   2级 → 3级：2 XP
*   3级 → 4级：4 XP
*   4级 → 5级：6 XP
*   5级 → 6级：8 XP
*   6级 → 7级：10 XP
*   7级 → 8级：12 XP
*   8级 → 9级：14 XP
*   9级 → 10级：16 XP
*   （10级以上公式：从当前 N 级升到 N+1 级，消耗 (N-1)×2 XP）
**2. 免费专业奖励**
*   当玩家将某技能提升至 **3级** 和 **5级** 时，ST必须提示玩家免费获得1个该技能下的【专业】。
*   *例外*：手艺、表达等带有子项的技能，子项达到3级/5级时不给免费奖励。
**3. 高阶技能经验减免**
当技能达到特定等级，玩家可选择一项以该技能为前提的专长/自创技能，获得购买该能力的 XP 减免：
*   达到 6级：减免 12 XP
*   达到 9级：减免 24 XP
*   达到 12级：减免 39 XP
*   达到 14级：减免 54 XP
*   *限制规则*：减免额度可叠加用于同一个能力（如12级累计减免75点），但不可分摊。每角色/每技能限用一次。若技能永久降低，回收该免费能力。
**4. 专长升级XP消耗**
*   1级(3XP) / 2级(6XP) / 3级(9XP) / 4级(12XP) / 5级(15XP)。
### 五、各技能覆盖领域参考
当玩家未明确技能时，参考以下索引（包含豁免归属）：
*   【运动】：投掷、弓箭、跳/爬/游、**反射豁免(运动-自我保护)**
*   【肉搏】：天生武器、擒抱/冲撞/摔绊、格挡
*   【驾驶】：轻重型载具、机甲操控
*   【枪械】：各类型枪械射击、重火力
*   【手上功夫】：开锁、盗窃、拆弹、精密操作
*   【躲藏】：潜行、隐藏物品
*   【求生】：野外求生、追踪、**强韧豁免(求生-自我保护)**
*   【白刃】：近战冷兵器攻击、格挡
*   【学识】：文件解读、历史/地理/怪物知识
*   【电脑】：黑客、防火墙、系统操作
*   【手艺】：对应子项的制造/修理/炼金等
*   【调查】：搜索、聆听、侦查破绽、读唇
*   【医学】：急救、手术、诊断、毒理分析
*   【神秘学】：施法、法术辨识、神秘仪式
*   【科学】：理科知识、图纸解析
*   【动物沟通】：骑术战斗、驯兽
*   【感受】：察言观色、坚定立场、**意志豁免(感受-自我保护)**
*   【表达】：唱歌/舞蹈/演讲等艺术表演
*   【胁迫】：威吓、强硬逼问
*   【交际】：交涉、说服、打探情报
*   【掩饰】：唬骗、易容、伪装、战斗虚招
### 六、技能使用与裁定
在处理玩家宣告的技能行动时，必须遵循以下具体的剧情推演与数值裁定逻辑：
**1. 检定类型切换与豁免日常判定**
*   **豁免日常**：角色进行无压力、无危险的日常行为（如普通开车、做饭、翻矮墙），ST应判定**自动成功**，无需投骰。
*   **纯属性/纯技能检定**：当行动完全依赖体能无适用技能时，仅用【关键属性】作DP；当行动极致依赖肌肉记忆流派时，仅用【技能等级】作DP。
**2. 失败后果与重试机制**
*   **条件重试**：多数常规检定失败后允许重试。但 ST 必须在叙事中施加惩罚：如时间流逝、引起警觉、难度(DC)临时提升等。
*   **一锤定音**：对于“失败即引发不可逆后果”的行动（如拆弹、危机场面交涉、悬崖跳跃），ST必须严格驳回重试请求，直接结算恶性后果。
**3. 团队协作判定裁定**
*   **协助与累计**：数值计算严格遵循《判定规则》中的“协助检定”与“延长检定”条款执行。
*   **独立判定**：对于潜行避敌、群体躲避陷阱等，ST必须要求队伍中**每个人各自独立检定**，任何一人失败都会导致相应的暴露或受损。
**4. 周期行动反噬警告**
*   针对需要多次判定的延长行动，若玩家触发大失败（投出“1”的数量超总DC），ST不仅要宣告【彻底失败】与资源清零，还必须**结合技能特性引发严重的反噬后果**（如黑客程序锁死、病人死亡、爆炸物引爆）。
**5. 奇迹挑战（超越凡人的DC）**
   凡人专家的正常DC一般不超过4-5。但针对超凡/半神角色的惊人之举（如一跃跳过大河、徒手接炮弹），ST可设定高达 DC10、DC20 甚至更高的门槛，允许玩家尝试，不得直接以“不符合物理定律”为由拒绝。
